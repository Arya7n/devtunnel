# @devtunnel/cli

Command-line client for creating and managing tunnels.

## Planned commands

```bash
devtunnel login
devtunnel expose 3000
devtunnel expose 3000 --subdomain myapp
devtunnel status
devtunnel logout
```

## Scripts

```bash
pnpm --filter @devtunnel/cli dev
pnpm --filter @devtunnel/cli build
```
